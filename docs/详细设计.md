## 1. 数据库详细表设计

### 1.1 users 用户表

**描述**：存储微信小程序用户的基本信息，包括境内外校友。

```sql
CREATE TABLE `users` (
  `id`           BIGINT       NOT NULL AUTO_INCREMENT COMMENT '用户ID',
  `openid`       VARCHAR(64)  NOT NULL COMMENT '微信OpenID',
  `union_id`     VARCHAR(64)  DEFAULT NULL COMMENT '微信UnionID',
  `nickname`     VARCHAR(100) DEFAULT NULL COMMENT '昵称',
  `avatar_url`   VARCHAR(500) DEFAULT NULL COMMENT '头像URL',
  `phone`        VARCHAR(20)  DEFAULT NULL COMMENT '手机号',
  `country_code` VARCHAR(10)  DEFAULT '+86' COMMENT '国家区号',
  `is_overseas`  TINYINT(1)   DEFAULT 0 COMMENT '是否海外用户：0否 1是',
  `is_verified`  TINYINT(1)   DEFAULT 0 COMMENT '是否已通过校友认证：0否 1是',
  `status`       TINYINT      DEFAULT 1 COMMENT '账号状态：1正常 0禁用',
  `created_at`   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at`   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `idx_openid` (`openid`),
  KEY `idx_union_id` (`union_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | BIGINT | PK AUTO_INCREMENT | 用户ID |
| openid | VARCHAR(64) | UNIQUE NOT NULL | 微信OpenID |
| union_id | VARCHAR(64) | NULL | 微信UnionID |
| nickname | VARCHAR(100) | NULL | 昵称 |
| avatar_url | VARCHAR(500) | NULL | 头像URL |
| phone | VARCHAR(20) | NULL | 手机号 |
| country_code | VARCHAR(10) | DEFAULT '+86' | 国家区号 |
| is_overseas | TINYINT(1) | DEFAULT 0 | 是否海外用户 |
| is_verified | TINYINT(1) | DEFAULT 0 | 是否校友认证通过 |
| status | TINYINT | DEFAULT 1 | 账号状态 |
| created_at | DATETIME | NOT NULL | 创建时间 |
| updated_at | DATETIME | NOT NULL | 更新时间 |

**索引**：`idx_openid`（唯一）、`idx_union_id`

### 1.2 alumni_verifications 校友认证表

**描述**：记录用户提交的校友身份认证申请及审核结果。

```sql
CREATE TABLE `alumni_verifications` (
  `id`              BIGINT       NOT NULL AUTO_INCREMENT COMMENT '认证记录ID',
  `user_id`         BIGINT       NOT NULL COMMENT '用户ID',
  `real_name`       VARCHAR(100) NOT NULL COMMENT '真实姓名',
  `student_id`      VARCHAR(50)  DEFAULT NULL COMMENT '学号',
  `graduation_year` YEAR         DEFAULT NULL COMMENT '毕业年份',
  `major`           VARCHAR(100) DEFAULT NULL COMMENT '专业',
  `proof_image_url` VARCHAR(500) DEFAULT NULL COMMENT '证明材料图片URL',
  `status`          ENUM('pending','approved','rejected') NOT NULL DEFAULT 'pending' COMMENT '审核状态',
  `reviewer_id`     BIGINT       DEFAULT NULL COMMENT '审核管理员ID',
  `review_remark`   VARCHAR(500) DEFAULT NULL COMMENT '审核备注',
  `reviewed_at`     DATETIME     DEFAULT NULL COMMENT '审核时间',
  `created_at`      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '申请时间',
  `updated_at`      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  KEY `idx_user_id` (`user_id`),
  KEY `idx_status` (`status`),
  KEY `idx_student_id` (`student_id`),
  CONSTRAINT `fk_av_user_id` FOREIGN KEY (`user_id`) REFERENCES `users` (`id`),
  CONSTRAINT `fk_av_reviewer_id` FOREIGN KEY (`reviewer_id`) REFERENCES `admins` (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='校友认证表';
```

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | BIGINT | PK AUTO_INCREMENT | 认证记录ID |
| user_id | BIGINT | FK users.id NOT NULL | 用户ID |
| real_name | VARCHAR(100) | NOT NULL | 真实姓名 |
| student_id | VARCHAR(50) | NULL | 学号 |
| graduation_year | YEAR | NULL | 毕业年份 |
| major | VARCHAR(100) | NULL | 专业 |
| proof_image_url | VARCHAR(500) | NULL | 证明材料图片URL |
| status | ENUM | DEFAULT 'pending' | 审核状态：pending/approved/rejected |
| reviewer_id | BIGINT | FK admins.id NULL | 审核管理员ID |
| review_remark | VARCHAR(500) | NULL | 审核备注 |
| reviewed_at | DATETIME | NULL | 审核时间 |
| created_at | DATETIME | NOT NULL | 申请时间 |
| updated_at | DATETIME | NOT NULL | 更新时间 |

**索引**：`idx_user_id`、`idx_status`、`idx_student_id`
**外键**：user_id → users.id，reviewer_id → admins.id

### 1.3 products 商品表

**描述**：存储校庆纪念品商品主信息。

```sql
CREATE TABLE `products` (
  `id`              BIGINT         NOT NULL AUTO_INCREMENT COMMENT '商品ID',
  `name`            VARCHAR(200)   NOT NULL COMMENT '商品名称（中文）',
  `name_en`         VARCHAR(200)   DEFAULT NULL COMMENT '商品名称（英文）',
  `description`     TEXT           DEFAULT NULL COMMENT '商品简介',
  `detail_html`     LONGTEXT       DEFAULT NULL COMMENT '图文详情HTML',

  `cover_image`     VARCHAR(500)   DEFAULT NULL COMMENT '封面图URL',
  `price`           DECIMAL(10,2)  NOT NULL COMMENT '基准价格（CNY）',

  `sales_count`     INT            DEFAULT 0 COMMENT '累计销量',
  `is_customizable` TINYINT(1)     DEFAULT 0 COMMENT '是否支持刻字定制',
  `status`          ENUM('draft','published','unpublished') NOT NULL DEFAULT 'draft' COMMENT '状态',
  `sort_order`      INT            DEFAULT 0 COMMENT '排序权重，越大越靠前',

  KEY `idx_sort_order` (`sort_order`),
```

### 1.10 orders 订单主表

**描述**：订单核心信息，记录下单金额、支付方式、状态流转及地址快照。

```sql
CREATE TABLE `orders` (
  `id`               BIGINT        NOT NULL AUTO_INCREMENT COMMENT '订单ID',
  `order_no`         VARCHAR(32)   NOT NULL COMMENT '订单编号',
  `user_id`          BIGINT        NOT NULL COMMENT '用户ID',
  `total_amount`     DECIMAL(10,2) NOT NULL COMMENT '订单总金额（CNY）',
  `currency`         VARCHAR(10)   DEFAULT 'CNY' COMMENT '支付货币',
  `exchange_rate`    DECIMAL(10,4) DEFAULT NULL COMMENT '下单时汇率（海外订单）',
  `address_id`       BIGINT        DEFAULT NULL COMMENT '收货地址ID',
  `address_snapshot` JSON          DEFAULT NULL COMMENT '下单时地址快照',
  `status`           ENUM('pending_payment','paid','processing','shipped','completed','cancelled','refunding','refunded') NOT NULL DEFAULT 'pending_payment' COMMENT '订单状态',
  `payment_method`   ENUM('wechat','paypal') DEFAULT NULL COMMENT '支付方式',
  `payment_id`       BIGINT        DEFAULT NULL COMMENT '支付记录ID',
  `remark`           VARCHAR(500)  DEFAULT NULL COMMENT '买家备注',
  `cancel_reason`    VARCHAR(200)  DEFAULT NULL COMMENT '取消原因',
  `expires_at`       DATETIME      DEFAULT NULL COMMENT '支付超时时间',
  `created_at`       DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at`       DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `idx_order_no` (`order_no`),
  KEY `idx_user_id` (`user_id`),
  KEY `idx_status` (`status`),
  KEY `idx_expires_at` (`expires_at`),
  CONSTRAINT `fk_orders_user` FOREIGN KEY (`user_id`) REFERENCES `users` (`id`),
  CONSTRAINT `fk_orders_addr` FOREIGN KEY (`address_id`) REFERENCES `addresses` (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='订单主表';
```

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | BIGINT | PK AUTO_INCREMENT | 订单ID |
| order_no | VARCHAR(32) | UNIQUE NOT NULL | 订单编号 |
| user_id | BIGINT | FK users.id NOT NULL | 用户ID |
| total_amount | DECIMAL(10,2) | NOT NULL | 订单总金额（CNY） |
| currency | VARCHAR(10) | DEFAULT 'CNY' | 支付货币 |
| exchange_rate | DECIMAL(10,4) | NULL | 下单时汇率（海外） |
| address_id | BIGINT | FK addresses.id NULL | 收货地址ID |
| address_snapshot | JSON | NULL | 下单时地址快照 |
| status | ENUM | DEFAULT 'pending_payment' | 订单状态 |
| payment_method | ENUM | NULL | 支付方式 |
| payment_id | BIGINT | FK payments.id NULL | 支付记录ID |
| remark | VARCHAR(500) | NULL | 买家备注 |
| cancel_reason | VARCHAR(200) | NULL | 取消原因 |
| expires_at | DATETIME | NULL | 支付超时时间 |
| created_at | DATETIME | NOT NULL | 创建时间 |
| updated_at | DATETIME | NOT NULL | 更新时间 |

**索引**：`idx_order_no`（唯一）、`idx_user_id`、`idx_status`、`idx_expires_at`

**订单状态流转**：

```
pending_payment → paid → processing → shipped → completed
      ↓                                              ↓
  cancelled                              refunding → refunded
```

#### 2.1.1 微信登录流程

**详细步骤说明**：

1. 用户点击登录，小程序调用 `wx.login()` 获取临时 code（有效期5分钟）
2. 小程序将 code POST 至 `/api/auth/wx-login`

4. 后端查询 `users` 表：
   - 若 openid 已存在：返回现有用户信息

5. 生成 JWT Token（payload含user_id、openid，有效期7天）
6. 返回 token 及用户基本信息给小程序
7. 小程序将 token 存入 storage，后续请求在 Header 中携带 `Authorization: Bearer {token}`

## 3. 关键算法设计

### 3.1 库存原子扣减

**设计目标**：高并发场景下防止超卖，保证库存数据一致性。

**两阶段扣减方案**：

```
阶段一：Redis 原子操作（快速拒绝超卖）

  SCRIPT:
    local stock = redis.call('GET', 'product:stock:' .. sku_id)
    if tonumber(stock) < quantity then
      return -1  -- 库存不足
    end
    return redis.call('DECRBY', 'product:stock:' .. sku_id, quantity)

  若返回值 < 0：
    INCRBY product:stock:{sku_id} quantity  -- 回滚 Redis
    返回"库存不足"错误

阶段二：MySQL 乐观锁兜底（数据持久化）

  UPDATE product_skus
  SET stock = stock - {quantity}
  WHERE id = {sku_id}
    AND stock >= {quantity}

  若受影响行数 = 0：
    INCRBY product:stock:{sku_id} quantity  -- 回滚 Redis
    返回"库存不足"错误

  若成功：
    同步更新 products.stock（冗余字段）
```

**库存初始化**（服务启动时）：

```python
# 从 MySQL 同步库存到 Redis
for sku in product_skus.query(status=1):
    redis.set(f'product:stock:{sku.id}', sku.stock)
```

**库存回滚**（订单取消/超时时）：

```python
# 1. Redis 回滚
redis.incrby(f'product:stock:{sku_id}', quantity)

# 2. MySQL 回滚
UPDATE product_skus SET stock = stock + {quantity} WHERE id = {sku_id}
```

### 3.2 订单超时自动关闭

**实现方案**：Redis Sorted Set 延迟队列 + 定时轮询

```python
# 创建订单时：将 expires_at 时间戳作为 score 写入 Sorted Set
expires_timestamp = int((datetime.now() + timedelta(minutes=30)).timestamp())
redis.zadd('order:timeout', {order_id: expires_timestamp})

# 定时任务（每30秒）：
def check_expired_orders():
    now = int(datetime.now().timestamp())
    # 获取所有已到期的订单ID
    expired_ids = redis.zrangebyscore('order:timeout', 0, now)

    for order_id in expired_ids:
        # 查询当前订单状态（避免重复处理）
        order = Order.get(order_id)
        if order and order.status == 'pending_payment':
            with db.transaction():
                # 关闭订单
                order.update(status='cancelled', cancel_reason='支付超时自动关闭')
                # 回滚库存
                for item in order.items:
                    rollback_stock(item.sku_id, item.quantity)
            # 从队列移除
            redis.zrem('order:timeout', order_id)
```

**幂等保障**：定时任务使用分布式锁（Redis SETNX），防止多实例并发执行。

### 3.3 汇率换算算法

**汇率获取优先级**：手动设置 > Redis缓存 > 数据库最新记录

```python
def get_exchange_rate(from_currency: str, to_currency: str) -> Decimal:
    key = f'exchange_rate:{from_currency}:{to_currency}'

    # 1. 从 Redis 获取（TTL 1小时，手动设置时 TTL 24小时）
    rate = redis.get(key)
    if rate:
        return Decimal(rate)

    # 2. 从数据库获取最新记录
    record = ExchangeRate.query(
        from_currency=from_currency,
        to_currency=to_currency
    ).order_by('-created_at').first()

    if record:
        redis.setex(key, 3600, str(record.rate))
        return record.rate

    raise Exception('汇率数据不可用')

def calculate_usd_price(cny_price: Decimal) -> Decimal:
    rate = get_exchange_rate('USD', 'CNY')
    usd_price = cny_price / rate
    return usd_price.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)
```

```python
def sync_exchange_rate():
```

### 3.5 刻字预览图生成算法

```python
from PIL import Image, ImageDraw, ImageFont
import io

def generate_preview(product_id: int, text: str, font_name: str) -> bytes:
    # 加载商品模板图（透明背景）
    template = Image.open(f'templates/{product_id}.png').convert('RGBA')

    # 加载字体
    font_path = f'fonts/{font_name}.ttf'
    font_size = calculate_font_size(text, template.width * 0.6)
    font = ImageFont.truetype(font_path, size=font_size)

    # 计算文字居中坐标
    draw = ImageDraw.Draw(template)
    bbox = draw.textbbox((0, 0), text, font=font)
    text_w = bbox[2] - bbox[0]
    text_h = bbox[3] - bbox[1]
    x = (template.width - text_w) / 2
    y = template.height * 0.75  # 文字区域在商品下方75%处

    # 渲染文字（金色 #D4AF37）
    draw.text((x, y), text, font=font, fill='#D4AF37')

    # 转换为 JPEG 输出
    output = io.BytesIO()
    template.convert('RGB').save(output, format='JPEG', quality=90)
    return output.getvalue()
```
