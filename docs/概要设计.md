## 1. 系统架构概述

### 1.1 整体架构

本系统采用前后端分离的分层架构设计，整体分为六层：

```
┌─────────────────────────────────────────────────────────┐
│                      客户端层                            │
│   ┌──────────────────────┐  ┌───────────────────────┐   │

│   └──────────────────────┘  └───────────────────────┘   │
└─────────────────────────┬───────────────────────────────┘
                          │ HTTPS
┌─────────────────────────▼───────────────────────────────┐
│                      网关层                              │
│   Nginx API Gateway                                      │
│   - 路由转发 / 负载均衡                                   │
│   - 限流 / 防刷（rate limiting）                         │
│   - HTTPS 终止 / SSL 卸载                                │

└──────────────┬────────────────────────┬─────────────────┘

┌──────────────▼──────────┐  ┌──────────▼──────────────────┐

│  - 商品 / 购物车         │  │   - 校友审核                 │
│  - 订单 / 支付           │  │   - 商品管理                 │

│  - 定制刻字 / 评价        │  │   - 数据统计 / 报表          │

│   │  - 主库（读写）      │  │  - 商品图片               │  │
```

**各层职责说明**

| 层级 | 组件 | 职责 |
|------|------|------|
| 客户端层 | 微信小程序 | 用户端交互，覆盖认购全流程 |
| 客户端层 | Web 管理后台 | 运营人员管理校友、商品、订单及数据统计 |
| 网关层 | Nginx | 统一入口、路由分发、限流保护、HTTPS 终止 |
| 应用服务层 | 主业务服务 | 面向 C 端的全部业务逻辑 |
| 应用服务层 | 管理服务 | 面向 B 端运营的管理逻辑 |
| 中间件层 | Redis | 会话存储、缓存、分布式锁 |
| 中间件层 | 消息队列 | 异步任务解耦（超时取消、通知、报表） |
| 数据层 | MySQL | 核心业务数据持久化 |
| 数据层 | OSS | 图片及文件对象存储 |
| 第三方服务 | 微信/支付/物流 | 外部能力集成 |

### 1.2 部署架构

系统部署在阿里云（或腾讯云）上，采用高可用方案：

```
                        ┌─────────────────┐
                        │   域名 / DNS     │
                        │  (HTTPS 证书)    │
                        └────────┬────────┘
                                 │
                        ┌────────▼────────┐
                        │   SLB 负载均衡   │
                        │  (阿里云 SLB)    │
                        └────┬───────┬────┘
                             │       │
              ┌──────────────▼──┐ ┌──▼──────────────┐
              │  Nginx 实例 A   │ │  Nginx 实例 B   │
              │  (API Gateway)  │ │  (API Gateway)  │
              └──────┬──────────┘ └──────────┬──────┘
                     │                        │
         ┌───────────▼────────────────────────▼──────────┐
         │                  应用集群                       │
         │  ┌────────────┐  ┌────────────┐               │
         │  │ App 实例 1  │  │ App 实例 2  │  ...          │
         │  └────────────┘  └────────────┘               │
         └────────────────┬───────────────────────────────┘
                          │
         ┌────────────────▼───────────────────────────────┐
         │              中间件集群                          │
         │  ┌────────────────┐  ┌───────────────────────┐  │
         │  │  Redis Cluster  │  │  RabbitMQ Cluster     │  │
         │  │  (主从/哨兵)    │  │  (镜像队列)            │  │
         │  └────────────────┘  └───────────────────────┘  │
         └────────────────┬───────────────────────────────┘
                          │
         ┌────────────────▼───────────────────────────────┐
         │              数据层                              │
         │  ┌──────────────────────────────────────────┐   │
         │  │  MySQL 主库 (读写)  →  MySQL 从库 (只读)  │   │
         │  │         主从同步 (binlog replication)      │   │
         │  └──────────────────────────────────────────┘   │
         │  ┌──────────────────────────────────────────┐   │
         │  │         阿里云 OSS (对象存储)              │   │
         │  └──────────────────────────────────────────┘   │
         └───────────────────────────────────────────────┘
```

**部署要点**

- 所有应用实例无状态化，Session 存储于 Redis，支持水平扩缩容
- MySQL 主从复制，写操作走主库，读操作走从库（读写分离）
- Redis 采用哨兵模式或 Cluster 模式，保证缓存高可用
- 消息队列采用镜像队列保证消息不丢失
- OSS 开启跨区域复制，保障文件持久性
- 全链路 HTTPS，敏感数据（支付、用户信息）加密传输

## 2. 模块划分

### 2.1 前端小程序模块

#### 2.1.1 认证模块

负责用户身份识别与校友资格核验，是系统访问的前置门槛。

- 微信授权登录（`wx.login` 获取 code，后端调用 `code2session`）
- 获取用户昵称、头像（引导式授权）
- 校友信息填写（学号、姓名、毕业年份、学院等）
- 校友认证状态轮询与展示（待审核 / 已通过 / 已拒绝）
- 手机号绑定（微信手机号快捷获取或手动填写）
- 登录态刷新与 Token 管理

#### 2.1.2 首页模块

系统入口页面，承载运营推广与商品导流。

- Banner 轮播图展示（可点击跳转商品或公告）
- 公告/活动通知展示
- 精选商品推荐区
- 快捷入口导航（商品分类、我的订单等）
- 校庆活动倒计时组件

#### 2.1.3 商品模块

覆盖商品浏览、搜索、详情查看全流程。

- 商品分类列表展示
- 商品列表（支持分页、排序、分类筛选）
- 关键词搜索
- 商品详情页（图片轮播、描述、规格参数）
- SKU 选择（规格组合选择，如颜色、尺寸）
- 库存实时展示
- 定制刻字入口引导

#### 2.1.4 购物车模块

用户临时存放意向商品的中转区。

- 添加商品至购物车（含 SKU 信息）
- 购物车列表展示与数量调整
- 选中 / 取消选中商品
- 删除购物车商品
- 购物车商品总价实时计算
- 一键下单（跳转结算页）

#### 2.1.5 订单模块

覆盖订单从创建到完结的完整生命周期。

- 结算页（地址确认、商品确认、定制信息确认、价格汇总）
- 提交订单（生成订单号）
- 订单列表（全部 / 待付款 / 待发货 / 待收货 / 已完成 / 售后）
- 订单详情（状态流转、物流信息、支付信息）
- 订单超时自动取消（15/30 分钟可配置）
- 主动取消订单（付款前）
- 确认收货
- 删除历史订单

#### 2.1.6 支付模块

支持人民币与外币两种支付方式，满足境内外校友需求。

- 微信支付（JSAPI 调起支付）
- PayPal 支付（境外校友，H5/WebView 跳转）
- 实时汇率展示（人民币 / 美元换算）
- 支付结果回调处理与页面跳转
- 支付超时提醒

#### 2.1.7 物流模块

管理收货地址与实时追踪包裹动态。

- 收货地址列表管理（新增、编辑、删除、设为默认）
- 微信地址快捷导入（`wx.chooseAddress`）
- 物流信息展示（快递公司、运单号、轨迹时间线）
- 快递100 接口实时拉取物流状态

#### 2.1.8 售后模块

提供退款、退货、换货等售后申请通道。

- 发起售后申请（选择类型：退款 / 退货退款 / 换货）
- 填写售后原因与上传凭证图片
- 售后进度跟踪
- 退款到账通知
- 查看售后处理结果

#### 2.1.9 定制刻字模块

支持用户对指定商品进行个性化刻字定制。

- 刻字内容输入（字符长度限制、敏感词过滤）
- 字体选择
- 实时刻字效果预览（Canvas 渲染或服务端合成预览图）
- 刻字信息与订单关联

#### 2.1.10 评价模块

订单完成后的商品评价功能，促进口碑传播。

- 订单完成后评价入口
- 星级评分（1-5 星）
- 文字评价
- 图片上传（最多 N 张）
- 商品详情页展示评价列表
- 追评功能

#### 2.1.11 消息通知模块

系统与用户的异步沟通通道。

- 消息通知中心列表
- 消息类型区分（订单状态、审核结果、物流动态、系统公告）
- 未读消息角标提示
- 微信订阅消息 / 模板消息推送接收
- 消息已读 / 一键全读

### 2.2 后端服务模块

后端采用单体分层（或可拆分为微服务）架构，对外暴露 RESTful API。

#### 用户服务（User Service）

- 微信 `code2session` 调用，OpenID 绑定与 Session 管理
- JWT Token 签发与验证
- 校友认证信息存储与状态流转
- 用户基础信息管理（昵称、头像、手机号）

#### 商品服务（Product Service）

- 商品 CRUD 与上下架管理
- SKU 矩阵管理（规格值笛卡尔积）
- 库存扣减（乐观锁 / Redis 原子操作防超卖）
- 商品分类树管理
- 图片 OSS 地址管理
- 商品搜索（MySQL LIKE 或 Elasticsearch 扩展）

#### 订单服务（Order Service）

- 订单号生成（雪花算法或 UUID）
- 订单状态机（待付款 → 已付款 → 待发货 → 已发货 → 已完成 → 已取消）
- 库存预占与释放
- 订单超时取消（消息队列延迟消息）
- 购物车清理
- 多订单批量查询

#### 支付服务（Payment Service）

- 微信支付统一下单（JSAPI）、支付回调验签
- PayPal Orders API v2 创建订单、捕获支付、Webhook 验证
- 退款申请（微信支付退款、PayPal 退款）
- 汇率查询与存储（定时任务拉取外部汇率接口）
- 支付流水记录

#### 物流服务（Logistics Service）

- 快递100 订阅查询接口集成
- 物流轨迹数据存储与增量更新
- 发货操作（填写快递公司与运单号）
- 物流状态变更触发通知

#### 售后服务（After-sales Service）

- 售后申请受理与审核流程
- 退款金额计算与退款触发
- 售后状态流转（待处理 → 处理中 → 已完成 / 已拒绝）
- 凭证图片管理

#### 定制服务（Customization Service）

- 刻字内容合法性校验（敏感词、字符集、长度）
- 预览图生成（服务端或前端 Canvas）
- 刻字信息与订单项绑定

#### 通知服务（Notification Service）

- 微信订阅消息 / 模板消息推送
- 站内消息写入与已读管理
- 消息模板管理
- 通知发送失败重试

#### 报表服务（Report Service）

- 数据聚合查询（订单量、销售额、校友分布等）
- 报表 Excel/PDF 生成
- 定时任务调度（日报、周报）
- SMTP 邮件发送报表附件

### 2.3 管理后台模块

- 审核结果自动触发通知

#### 商品管理模块

- 商品新增 / 编辑 / 删除 / 上下架
- SKU 规格配置与价格库存维护
- 商品分类管理
- 图片上传（OSS）
- 批量导入商品（Excel）
- 商品排序权重设置

#### 订单管理模块

- 订单列表（多条件筛选：状态、时间、校友、商品）
- 订单详情查看
- 发货操作（填写快递信息）
- 手动关闭订单
- 订单备注
- 订单数据导出（Excel）

#### 售后处理模块

- 售后申请列表与详情
- 审核通过 / 拒绝
- 触发退款操作
- 换货处理流程
- 售后统计

#### 统计报表模块

- 销售概览仪表盘（今日 / 本周 / 本月）

## 3. 技术选型建议

### 3.1 前端技术栈

| 类别 | 推荐选型 | 备选方案 | 说明 |
|------|---------|---------|------|
| 小程序框架 | Taro 3.x (React/Vue3) | uni-app、原生微信小程序 | Taro 生态成熟，跨端能力强 |
| UI 组件库 | Vant Weapp | uView UI、NutUI | Vant 文档完善，组件丰富 |
| 状态管理 | Pinia (Vue3) / Zustand (React) | Vuex、Redux | 轻量，适合中型项目 |
| HTTP 请求 | Taro.request 封装 | axios-miniprogram | 统一拦截器、Token 刷新 |
| 样式方案 | SCSS | Less | 嵌套变量支持，维护性好 |

### 3.2 后端技术栈

| 类别 | 推荐选型 | 备选方案 | 说明 |
|------|---------|---------|------|
| 语言框架 | Node.js + Koa2 / NestJS | Java Spring Boot、Python FastAPI | NestJS 提供装饰器 DI，结构清晰 |
| 数据库 | MySQL 8.0 | PostgreSQL | 事务支持完善，社区成熟 |
| ORM | Prisma (Node) / MyBatis-Plus (Java) | Sequelize、TypeORM | Prisma 类型安全，迁移管理方便 |
| 缓存 | Redis 7.x | Memcached | 支持多种数据结构，功能全面 |
| 消息队列 | RabbitMQ | Redis Delayed Queue、Kafka | 可靠性高，死信队列支持超时处理 |
| API 规范 | RESTful + OpenAPI 3.0 (Swagger) | GraphQL | 前后端契约清晰 |
| 认证授权 | JWT (access token + refresh token) | Session + Redis | 无状态，适合多实例部署 |
| 文件上传 | 阿里云 OSS 服务端签名直传 | 后端中转上传 | 减轻服务器带宽压力 |

### 3.3 基础设施

| 类别 | 推荐选型 | 备选方案 | 说明 |
|------|---------|---------|------|
| Web 服务器 | Nginx 1.24+ | Caddy | 反代、限流、静态服务 |
| 容器化（开发） | Docker + Docker Compose | 直接安装 | 环境一致，快速搭建 |
| 容器化（生产） | K8s (阿里云 ACK) | Docker Swarm | 按需扩缩容，自愈能力 |

## 4. 数据库概要设计

### 4.1 ER 图文字描述

以下描述各核心实体之间的关联关系：

```
用户 (users)
  │
  ├── 1:1 ──→ 校友认证 (alumni_verifications)        用户发起一次认证申请
  │
  ├── 1:N ──→ 收货地址 (addresses)                   用户可有多个地址
  │
  ├── 1:N ──→ 购物车明细 (cart_items)                 购物车归属用户
  │
  └── 1:N ──→ 订单 (orders)                          用户下多个订单
                │
                ├── 1:N ──→ 订单明细 (order_items)   一单含多个商品项
                │              │
                │              └── 0:1 ──→ 刻字定制 (customizations)
                │
                ├── 1:1 ──→ 支付记录 (payments)
                │
                ├── 1:N ──→ 物流信息 (logistics)
                │
                └── 0:1 ──→ 售后申请 (after_sales)

商品 (products)
  │
  ├── N:N ──→ 商品分类 (product_categories)          通过关联表实现
  │
  ├── 1:N ──→ 商品 SKU (product_skus)               颜色/尺寸等规格组合
  │
  ├── 1:N ──→ 商品图片 (product_images)
  │
  └── 1:N ──→ 商品评价 (reviews)
                │
                └── 1:N ──→ 评价图片 (review_images)

购物车明细 (cart_items)
  └── N:1 ──→ 商品 SKU (product_skus)               明细指向具体 SKU

管理员 (admins)
  └── N:N ──→ 角色 (roles)                           通过 admin_roles 关联
                └── N:N ──→ 权限 (permissions)       通过 role_permissions 关联
```

### 4.2 主要数据表列表

| 27 | `exchange_rates` | 汇率记录 | 货币对（USD/CNY 等）、汇率值、来源、记录时间 |
| 28 | `report_schedules` | 报表邮件计划 | 报表类型、周期（日/周/月）、收件人邮件列表、最近执行时间 |

## 附录

### 附录 A：接口规范约定

- 所有 API 路径以 `/api/v1/` 为前缀
- 认证方式：请求头携带 `Authorization: Bearer <token>`
- 响应格式统一为：
  ```json
  {
    "code": 0,
    "message": "success",
    "data": {}
  }
  ```
- 错误码规范：`0` 成功，`1xxx` 业务错误，`4xx` HTTP 错误，`5xx` 服务器错误
- 分页参数：`page`（页码，从 1 起）、`pageSize`（每页条数，默认 20）
- 时间格式：ISO 8601 字符串（`2026-03-09T12:00:00+08:00`）

### 附录 B：关键状态枚举

**订单状态（orders.status）**

| 值 | 含义 |
|----|------|
| `pending_payment` | 待付款 |
| `paid` | 已付款 |
| `pending_shipment` | 待发货 |
| `shipped` | 已发货 |
| `completed` | 已完成 |
| `cancelled` | 已取消 |
| `after_sales` | 售后中 |

**校友认证状态（alumni_verifications.status）**

| 值 | 含义 |
|----|------|
| `pending` | 待审核 |
| `approved` | 已通过 |
| `rejected` | 已拒绝 |

**售后类型（after_sales.type）**

| 值 | 含义 |
|----|------|
| `refund_only` | 仅退款 |
| `return_refund` | 退货退款 |
| `exchange` | 换货 |

**支付方式（payments.payment_method）**

| 值 | 含义 |
|----|------|
| `wechat_pay` | 微信支付 |
| `paypal` | PayPal |
