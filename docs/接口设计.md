## 1. 接口规范

### 1.1 设计原则

本项目 API 遵循 RESTful 设计规范：

- 使用标准 HTTP 方法表达操作语义：`GET`（查询）、`POST`（创建）、`PUT`（全量更新）、`PATCH`（局部更新）、`DELETE`（删除）
- URL 使用名词复数形式，资源层级通过路径嵌套体现
- HTTP 状态码用于表示请求级别的成功/失败，业务错误通过响应体 `code` 字段区分
- 接口保持无状态，认证信息随每次请求携带

### 1.2 Base URL

| 端                | Base URL              |
|-------------------|-----------------------|
| 小程序端（用户侧）  | `/api/v1`             |
| 管理后台（后台侧）  | `/admin/api/v1`       |

### 1.3 认证方式

所有需要登录的接口必须在请求头中携带 JWT Bearer Token：

```http
Authorization: Bearer <token>
```

- Token 由登录接口（`/auth/wx-login` 或 `/admin/auth/login`）返回
- Token 默认有效期 **2 小时**，过期后可通过 `/auth/refresh-token` 刷新
- 管理后台 Token 与小程序 Token 相互独立

### 1.4 Content-Type

```http
Content-Type: application/json
```

文件上传接口使用：

```http
Content-Type: multipart/form-data
```

### 1.5 统一响应格式

所有接口均返回如下 JSON 结构：

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "timestamp": 1710000000
}
```

| 字段        | 类型    | 说明                          |
|-------------|---------|-------------------------------|
| `code`      | integer | 业务状态码，0 表示成功         |
| `message`   | string  | 描述信息                      |
| `data`      | object  | 响应数据，失败时可为 `null`    |
| `timestamp` | integer | 服务端 Unix 时间戳（秒）       |

### 1.6 分页格式

涉及列表查询的接口，`data` 字段统一为：

```json
{
  "list": [],
  "page": 1,
  "pageSize": 20,
  "total": 100
}
```

查询参数：

| 参数       | 类型    | 默认值 | 说明             |
|------------|---------|--------|------------------|
| `page`     | integer | 1      | 当前页码（≥1）   |
| `pageSize` | integer | 20     | 每页条数（1-100）|

### 1.7 请求签名（敏感操作）

涉及支付、退款等敏感操作，需在请求头附加以下签名字段：

```http
X-Nonce: <随机字符串，长度16-32>
X-Timestamp: <Unix时间戳（秒）>
X-Signature: <HMAC-SHA256(appSecret, method+url+timestamp+nonce+body)>
```

服务端校验时间戳偏差不超过 **300 秒**，相同 nonce 不可重复使用。

### 2.1 认证模块 (REQ-001~REQ-010)

#### 2.1.1 微信登录

**`POST /api/v1/auth/wx-login`**

> REQ-001、REQ-002：用户通过微信授权登录，使用 code 换取平台 token。

**请求体**

| 字段         | 类型   | 必填 | 说明                                |
|--------------|--------|------|-------------------------------------|
| `code`       | string | 是   | 微信小程序 `wx.login()` 返回的 code |
| `nickName`   | string | 否   | 用户昵称（来自用户信息授权）         |
| `avatarUrl`  | string | 否   | 用户头像 URL                        |

**请求示例**

```json
{
  "code": "0e1Ttz100KbByB1u9y400kP5KH1Ttz1F",
  "nickName": "张三",
  "avatarUrl": "https://thirdwx.qlogo.cn/..."
}
```

**响应数据**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refreshToken": "dGhpcyBpcyBhIHJlZnJlc2ggdG9rZW4...",
    "expiresIn": 7200,
    "userId": "u_abc123",
    "isAlumni": false,
    "alumniStatus": "none"
  },
  "timestamp": 1710000000
}
```

| 字段           | 类型    | 说明                                                                 |
|----------------|---------|----------------------------------------------------------------------|
| `token`        | string  | JWT 访问 Token                                                       |
| `refreshToken` | string  | 刷新 Token，有效期 30 天                                             |
| `expiresIn`    | integer | Token 有效时长（秒）                                                 |
| `userId`       | string  | 平台用户 ID                                                          |
| `isAlumni`     | boolean | 是否已通过校友认证                                                   |
| `alumniStatus` | string  | 认证状态：`none`/`pending`/`approved`/`rejected`/`system_linked`    |

| `major`         | string | 是   | 专业名称                        |

| `email`         | string | 否   | 邮箱                            |
| `proofFiles`    | File[] | 是   | 证明文件（毕业证/学生证照片），最多3个 |

**响应数据**

```json
{
  "code": 0,

    "applyId": "apply_20240101_001",

```

## 4. 文件上传接口

### 4.1 上传图片

**`POST /api/v1/upload/image`**

> 用于评价图片、头像等场景的图片上传。需携带 Token。

**Content-Type**: `multipart/form-data`

**请求参数**

| 字段     | 类型   | 必填 | 说明                               |
|----------|--------|------|------------------------------------|
| `file`   | File   | 是   | 图片文件                           |
| `scene`  | string | 否   | 使用场景：`review`/`avatar`/`after_sale`，用于分目录存储 |

**限制**

| 项目         | 限制值                             |
|--------------|------------------------------------|
| 支持格式     | `JPG`、`JPEG`、`PNG`、`WEBP`、`GIF`（静图） |
| 最大文件大小 | **10 MB**                          |
| 最大分辨率   | 4096 × 4096 px                     |

**响应数据**

```json
{
  "code": 0,
  "message": "上传成功",
  "data": {
    "fileId": "img_abc123",
    "url": "https://cdn.example.com/images/img_abc123.jpg",
    "width": 1080,
    "height": 720,
    "size": 245678,
    "mimeType": "image/jpeg"
  },
  "timestamp": 1710000000
}
```

---

### 4.2 上传证明文件

**`POST /api/v1/upload/document`**

> 用于校友认证的毕业证、学生证等证明材料上传。需携带 Token。

**Content-Type**: `multipart/form-data`

**请求参数**

| 字段       | 类型   | 必填 | 说明                    |
|------------|--------|------|-------------------------|
| `file`     | File   | 是   | 文件                    |
| `category` | string | 否   | 文件类别：`graduation_cert`（毕业证）/`student_card`（学生证）/`other` |

**限制**

| 项目         | 限制值                              |
|--------------|-------------------------------------|
| 支持格式     | `JPG`、`JPEG`、`PNG`、`PDF`        |
| 最大文件大小 | **20 MB**                           |

**响应数据**

```json
{
  "code": 0,
  "message": "上传成功",
  "data": {
    "fileId": "doc_xyz789",
    "url": "https://cdn.example.com/documents/doc_xyz789.pdf",
    "name": "毕业证.pdf",
    "size": 1048576,
    "mimeType": "application/pdf",
    "uploadedAt": "2024-01-01T10:00:00Z"
  },
  "timestamp": 1710000000
}
```

---

### 4.3 上传说明

- 所有上传接口均通过 OSS 对象存储（阿里云 OSS / 腾讯云 COS）托管，返回的 URL 为 CDN 加速地址
- 服务端会对文件做病毒扫描和内容安全检测（合规审查），违规文件将被拒绝并返回错误
- 上传的证明文件（`/upload/document`）URL 仅管理员和用户本人可访问，需经过鉴权签名
- 文件上传成功后，将返回的 `url` 字段值作为后续业务接口（如申请校友认证、提交评价）的入参
